{{- /* DOC-1408: map each served version segment to one the search index actually carries. The index is faceted by `version` x `variant`, where `version` is the first path segment under /docs/. Not every served segment is indexed: the Algolia crawler excludes the pinned version trees (each is a near-complete copy of the corpus, ~37k records apiece), so filtering on a pin's own segment matches zero records and the search box comes back empty -- which is what /docs/latest did until the crawler stopped excluding it. Rather than hardcode a second list that can drift from the crawler config, derive it from the version menu: badged entries (LATEST / STABLE) are the built-and-indexed trees, bare numbered entries are the pins. A pin falls back to its own line's stable, so a reader on a pinned tree gets that line's results instead of nothing. */ -}} {{- $searchVersions := dict -}} {{- with site.Params.version_menu -}} {{- range $g := (. | transform.Unmarshal) -}} {{- range $it := $g.items -}} {{- if $it.badge -}} {{- $searchVersions = merge $searchVersions (dict $it.seg $it.seg) -}} {{- else -}} {{- $searchVersions = merge $searchVersions (dict $it.seg $g.line) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
